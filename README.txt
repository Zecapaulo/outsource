Conteúdo:
- index.html
- style.css
- script.js
- images/fundador.jpg

Como abrir:
1. Extraia o ficheiro ZIP.
2. Abra index.html num navegador com ligação à internet.

A página utiliza Bootstrap 5.3 e a fonte Manrope através de CDN.
Os formulários demonstram validação no navegador e não enviam dados para um servidor.
Substitua o telefone, e-mail e endereço pelos dados oficiais antes de publicar.
